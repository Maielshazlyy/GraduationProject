using action context AI-->>RGS: replyText (conversational) RGS-->>CCS: string replyText end CCS->>DB: Save AI Reply Message
{ SenderType: "AI", Content: replyText } CCS-->>API: ChatResponseDTO API-->>C: { replyText, orderId?, ticketId?, cart?, recommendations?, status }
Supported Intents & Actions
CreateOrder
Creates Order + OrderItems, calculates cart, fetches recommendations from menu
Complaint
Creates Ticket with type/priority from AI escalation data
AskAboutOrderStatus
Fetches latest order status for the customer
CancelOrder
Updates Order.Status to Cancelled
RequestHumanAgent
Creates escalation Ticket, routes to available agent
AskAboutProducts / GeneralQuestion
No DB action — AI responds using KnowledgeBase context
🎤 AI Voice Flow WebSocket / SignalR
Voice calls are handled over WebSocket (SignalR). Audio streams in real-time — no files saved. Adds Speech-to-Text and Text-to-Speech on top of the chat flow.

Voice vs Chat — Differences
Aspect 💬 Chat 🎤 Voice
Transport REST API (HTTP POST) WebSocket (SignalR)
Input format Text string Audio chunks (streaming)
Extra AI steps — Speech-to-Text + Text-to-Speech
File storage — None — real-time streaming only
Session model Stateless per request Stateful session (CallSessionId)
Shared steps Intent Detection · Sentiment · Business Logic · Response Generation
End artifact Text reply in JSON Audio stream + CallSummary saved to DB
