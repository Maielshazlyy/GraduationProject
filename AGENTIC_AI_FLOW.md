# 🤖 Agentic AI Flow - تدفق الـ Agentic AI

## 🎯 المفهوم الأساسي

**التقسيم واضح:**
- **AI** → يديك الـ **Intent** (النية)
- **Backend** → ينفذ الـ **Business Logic** بناءً على الـ Intent
- **Backend** → يخبر AI إنه نفذ (ماذا حدث)
- **AI** → يولد الرد بناءً على النتيجة
- **Backend** → يبعته للـ Frontend

**التوصيات (Recommendations):**
- **Backend** يحسب التوصيات (مثلاً: برجر → يقترح بطاطس، مشروب) ويبعتها في ActionData
- **AI** يستقبلها ويضيفها في الرد بشكل طبيعي للعميل (Chat أو Voice)

## 📋 أدوار كل طرف

### AI:
1. **Intent Detection:** يديك النية (CreateOrder, Complaint, etc.) + Entities
2. **Response Generation:** بعد ما Backend يخبره إنه نفذ، AI يولد الرد

### Backend (أنت):
1. **استقبال** الرسالة
2. **إرسال** للـ AI → Intent Detection
3. **تنفيذ** Business Logic بناءً على الـ Intent
4. **إخبار** AI بالنتيجة (ActionOutcome + ActionData)
5. **استلام** الرد من AI
6. **إرسال** الرد للـ Frontend

### Frontend:
- **عرض** الرد للعميل

---

## ⭐ النقاط الأساسية

| الخطوة | من | إلى | ماذا |
|--------|-----|-----|------|
| 1 | AI | Backend | **Intent** (النية) |
| 2 | Backend | - | **ينفذ Business Logic** (إنشاء طلب، تذكرة، إلخ) |
| 3 | Backend | AI | **يخبره إنه نفذ** (ActionOutcome + ActionData) |
| 4 | AI | Backend | **الرد** (نص) |
| 5 | Backend | Frontend | **الرد** (نفس اللي من AI) |

---

## 📝 مثال عملي

**العميل يقول:** "عايز أطلب برجر كبير"

1. **AI Intent Detection** → يرجع: `Intent: CreateOrder`, `Entities: { product: برجر, size: كبير }`

2. **Backend** → ينفذ:
   - ينشئ Order
   - يحسب Cart
   - يجيب Recommendations
   - النتيجة: `orderId: "ord-123"`, `cart: {...}`, `recommendations: [...]`

3. **Backend** → يرسل للـ AI:
   ```
   ActionOutcome: "OrderCreated"
   ActionData: { orderId: "ord-123", totalPrice: 50, items: [...], recommendations: [...] }
   ```

4. **AI** → يولد الرد:
   ```
   "تمام! سجلت لك برجر كبير. الإجمالي 50 جنيه. عايز تضيف بطاطس أو مشروب؟"
   ```

5. **Backend** → يبعته للـ Frontend كما هو

## 🔧 التطبيق التقني

### ما يرسله Backend للـ AI (Response Generation):
```csharp
{
    intent: "CreateOrder",
    actionOutcome: "OrderCreated",  // ماذا نفذ Backend
    actionData: {                   // نتيجة التنفيذ
        orderId: "ord-123",
        totalPrice: 50,
        cartItems: [...],
        recommendations: [...]
    },
    recentMessages: [...],
    detectedLanguage: "ar",
    detectedDialect: "Egyptian"
}
```

### ما يرجعه AI:
```
"تمام! سجلت لك برجر كبير. الإجمالي 50 جنيه. عايز تضيف بطاطس أو مشروب؟"
```
(التوصيات كانت في ActionData — AI أضافها في الرد بشكل طبيعي)

### ما يرسله Backend للـ Frontend:
```json
{
    "replyText": "تمام! سجلت لك برجر كبير. الإجمالي 50 جنيه. عايز تضيف بطاطس أو مشروب؟",
    "orderId": "ord-123",
    "cart": {...},
    ...
}
```

## ✅ الخلاصة

- **AI** يديك **Intent** → أنت تنفذ **Business Logic**
- أنت تخبر **AI** إنك نفذت → **AI** يولد **الرد**
- أنت تبعته للـ **Frontend** → يعرضه للعميل

**Backend = منفذ + وسيط.**  
**AI = مكتشف النية + مولّد الرد.**
