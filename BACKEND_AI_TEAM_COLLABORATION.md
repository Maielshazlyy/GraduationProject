### 2. **Integration Points / نقاط التكامل**

Backend calls AI services at these points:

Backend يستدعي خدمات AI في هذه النقاط:

#### a) **Intent Detection / اكتشاف النية**
**Called in:**
- `CustomerChatService.HandleMessageAsync` (line ~100)
- `CustomerVoiceService.HandleVoiceMessageAsync` (line ~100)

**Flow:**
1. Customer sends message (text or audio)
2. If audio: Convert to text first (Speech-to-Text)
3. Backend calls `_intentDetectionService.DetectIntentAsync(...)`
4. Backend receives `DetectedIntentResultDTO`
5. Backend processes intent and executes business logic

#### b) **Sentiment Analysis / تحليل المشاعر**
**Called in:**
- `CustomerChatService.HandleMessageAsync` (after message processing)
- `CustomerVoiceService.HandleVoiceMessageAsync` (after message processing)

**Flow:**
1. Customer message is processed
2. Backend calls `_sentimentService.AnalyzeSentimentAsync(...)`
3. Backend receives `Sentiment` object
4. Backend saves sentiment to database
5. Sentiment is linked to the message

#### c) **Speech-to-Text / تحويل الصوت إلى نص**
**Called in:**
- `CustomerVoiceService.HandleVoiceMessageAsync` (line ~62)

**Flow:**
1. Customer sends audio message
2. Backend calls `ConvertAudioToTextAsync(audioData, format)`
3. Backend receives transcribed text
4. Text is used for intent detection

#### d) **Text-to-Speech / تحويل النص إلى صوت**
**Called in:**
- `CustomerVoiceService.HandleVoiceMessageAsync` (line ~248, currently commented)

**Flow:**
1. Backend generates text response
2. Backend calls `ConvertTextToAudioAsync(text, settings, dialect)`
3. Backend receives audio file (Base64)
4. Audio is returned to customer in `CustomerChatResponseDTO.ReplyAudio`

public async Task<Sentiment> AnalyzeSentimentAsync(
    string messageId,
    string messageText,
    string language = "ar")
{
    // TODO: Replace with actual AI API call
    // Example using Azure Text Analytics:
    
    var client = new TextAnalyticsClient(
        new Uri("https://your-endpoint.cognitiveservices.azure.com/"),
        new AzureKeyCredential("your-api-key")
    );
    
    var documents = new List<TextDocumentInput>
    {
        new TextDocumentInput(messageId, messageText)
        {
            Language = language
        }
    };
    
    var response = await client.AnalyzeSentimentBatchAsync(documents);
    
    var result = response.Value[0];
    
    // Map AI response to Sentiment model
    var sentiment = new Sentiment
    {
        SentimentId = Guid.NewGuid().ToString(),
        MessageId = messageId,
        SourceText = messageText,
        AnalyzedAt = DateTime.UtcNow,
        Score = MapSentimentToScore(result.DocumentSentiment),
        Label = result.DocumentSentiment.Label.ToString()
    };
    
    return sentiment;
}

private double MapSentimentToScore(TextSentiment sentiment)
{
    return sentiment switch
    {
        TextSentiment.Positive => 0.5 + (sentiment.ConfidenceScores.Positive * 0.5),
        TextSentiment.Negative => -0.5 - (sentiment.ConfidenceScores.Negative * 0.5),
        _ => 0.0
    };
}
```

private async Task<(string audioBase64, string audioFormat)> ConvertTextToAudioAsync(
    string text,
    VoiceSettingsDTO settings,
    string? dialect)
{
    // TODO: Replace with actual Text-to-Speech API
    // Example using Azure Text-to-Speech:
    
    var config = SpeechConfig.FromSubscription("your-subscription-key", "your-region");
    
    // Select voice based on settings and dialect
    string voiceName = SelectVoice(settings, dialect);
    config.SpeechSynthesisVoiceName = voiceName;
    
    // Set speech rate (speed)
    config.SetSpeechSynthesisOutputFormat(SpeechSynthesisOutputFormat.Audio16Khz32KBitRateMonoMp3);
    
    using var synthesizer = new SpeechSynthesizer(config);
    
    var ssml = $@"
        <speak version='1.0' xml:lang='{settings.AgentVoiceLanguage}'>
            <voice name='{voiceName}'>
                <prosody rate='{settings.AgentVoiceSpeed}' pitch='{settings.AgentVoicePitch}'>
                    {text}
                </prosody>
            </voice>
        </speak>";
    
    var result = await synthesizer.SpeakSsmlAsync(ssml);
    
    if (result.Reason == ResultReason.SynthesizingAudioCompleted)
    {
        var audioBase64 = Convert.ToBase64String(result.AudioData);
        return (audioBase64, "audio/mp3");
    }
    else
    {
        throw new Exception($"Text-to-speech failed: {result.Reason}");
    }
}

private string SelectVoice(VoiceSettingsDTO settings, string? dialect)

    // Select appropriate voice based on language and dialect
    if (settings.AgentVoiceLanguage == "ar")

        return dialect == "Egyptian"

            : "ar-SA-ZariyahNeural"; // Standard Arabic voice
    }
    else
    {
        return "en-US-JennyNeural"; // English voice
    }
}

Backend → Processes Intent & Generates Response Text
    ↓
Backend → ISentimentService.AnalyzeSentimentAsync()
    ↓
AI Team → Returns Sentiment
    ↓
Backend → Saves Sentiment to Database
    ↓
Backend → ConvertTextToAudioAsync()
    ↓
AI Team → Returns Audio (Base64)
    ↓
Backend → Returns Audio Response to Customer
```
